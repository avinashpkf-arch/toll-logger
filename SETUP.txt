TOLL DETOUR COUNTER – SETUP (one time)

App link (open in Chrome on all eight phones):
   https://avinashpkf-arch.github.io/toll-logger/
Chrome menu (⋮) > Install app / Add to Home screen, so it opens like an app.

1. GOOGLE SHEET (once, on a computer)
   a. Open https://raw.githubusercontent.com/avinashpkf-arch/toll-logger/main/Code.gs  > Ctrl+A > Ctrl+C
   b. Open your Google Sheet > Extensions > Apps Script. Ctrl+A, Delete (the editor must be EMPTY,
      no "function myFunction"), Ctrl+V, Save.
      (No sheet? The script creates "Toll Audit Live" in your Drive by itself.)
   c. Deploy > New deployment > gear > Web app.  Execute as: Me.  Who has access: Anyone.  Deploy.
      Authorize access > your account > Advanced > Go to … (unsafe) > Allow.
   d. Copy the Web app URL (ends with /exec). Open it in Chrome: it must show {"ok":true,...}
   Already deployed? After pasting new code: Deploy > Manage deployments > pencil > New version > Deploy
   (keeps the same link). Phones that are open switch over by themselves within 2 minutes.

   How the sheet works (script version 2)
   - Vehicles go into the tab "Records" (11 columns). Every save is ADDED as a new row, so an edit or a
     delete shows up as an extra row for the same vehicle. The tab is a log: use the app's Excel for counts.
   - Rows are added automatically as needed. One spreadsheet holds about 900,000 rows; after that the
     script starts "Toll Audit Live (2)", "(3)" … in your Drive by itself. No practical limit.
   - An old "Log" tab from the earlier version is no longer used; you can delete it.
   - Rows with detour "LOGIN" record which post logged in on which phone, and when. They are not vehicles.

2. LOGINS AND THE EIGHT PHONES
   There are 9 IDs: one per post plus Admin. PINs are handed out by the admin (they are not in this file).
       LHS Kaniyur  Entry / Exit      LHS LMW      Entry / Exit
       RHS Kaniyur  Entry / Exit      RHS Rangaz   Entry / Exit      Admin
   - Admin, once: log in as Admin > Setup > paste the /exec link > Save and test >
     "Send setup link to the guides" (shares or copies a link that already contains the Sheet link).
   - Each guide: open the setup link > tap their post > type their PIN. Done – the phone is locked to that post.
   - A post ID works on ONE phone at a time. If it logs in on another phone, the first phone sends what it
     typed and logs itself out (within about 10 seconds of being online). This stops two people counting one post.
   - Guides see only their own post's vehicles and counts. Only Admin sees all posts, "Posts right now"
     (last login and last vehicle per post – amber if nothing for 15 minutes) and the Excel.
   - 5 wrong PINs in a row: the login waits 30 seconds.
   - Log out: Account (guides) / Setup (admin) > Log out. If vehicles are not sent yet it warns first.
   - Turn on automatic date & time on every phone (entry and exit times must line up).

3. COUNTING (Count tab)
   - The top of the screen shows the logged-in post, e.g. "LHS Kaniyur · Entry".
   - Tap the vehicle type (Car, LCV, Truck, Bus, MAV). It stays selected for the next vehicles.
   - Type the LAST 4 DIGITS of the number plate. It saves by itself on the 4th digit (phone buzzes twice).
   - Fewer than 4 digits on the plate? Type them and press Save.
   - ⌫ removes a digit; hold ⌫ to clear. "Undo last" removes the last saved vehicle.
   - The same number in different categories is fine (e.g. Car 1234 and Truck 1234 are different vehicles).
   - Same number AND same type twice within 2 minutes at one post: it still saves but warns you, so you can Undo.
   - The last 5 entries are listed below; ✕ deletes one. Corrections: Records tab, change the number or type.

4. MATCH AND EXCEL (Admin only: Records tab, once all eight phones have synced)
   - Each detour is matched on its own: LHS Kaniyur entries with LHS Kaniyur exits, LHS LMW with LHS LMW,
     RHS Kaniyur with RHS Kaniyur, RHS Rangaz with RHS Rangaz.
   - No time limit: each exit is matched with the closest earlier entry on its paired route with the same
     4 digits AND the same vehicle type. Only leftovers are then paired across types (a guide may have tapped
     the wrong type) – these show "Same type: No". Times are when each phone saved the vehicle.
   - "Also match likely typos" (on by default): one digit wrong or two digits swapped, only for the same
     vehicle type and within 30 minutes, and only after exact matches are taken. Marked "Typo" in the Excel.
   - Match and download Excel. Sheets:
       Summary – per detour: entries, exits, matched (exact / typo / by type), unmatched
       LHS Kaniyur Entry, LHS Kaniyur Exit, LHS LMW Entry, LHS LMW Exit,
       RHS Kaniyur Entry, RHS Kaniyur Exit, RHS Rangaz Entry, RHS Rangaz Exit
                – every vehicle at each post with its time and its match
       Matched   – all matched pairs (detour, entry and exit number, times, match type, same vehicle type?)
       Unmatched – entries with no exit and exits with no entry, by detour

Notes
- Anyone with the /exec link can read and write the log. Share it only with the team and archive the
  deployment (Deploy > Manage deployments > Archive) when the audit is over.
- "Clear this phone" wipes the phone and unlinks it. The Google Sheet keeps its copy.
